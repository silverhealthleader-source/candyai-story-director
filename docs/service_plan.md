# StoryForge Prompt Studio 서비스 기획서

> 첨부 문서는 참고 자료로만 사용했으며, 실제 구현 기준은 현재 사용자의 요청과 과제 조건입니다.

## 1. 서비스 개요

- 서비스명: StoryForge Prompt Studio
- 목적: 한 줄 이야기 아이디어를 전문적인 영상 스토리보드, 캐릭터 시트 생성 프롬프트, 이미지 생성 프롬프트, 영상 생성 프롬프트, 수노 음악 프롬프트로 확장한다.
- 타겟 사용자: 동화책 작가, AI 이미지·영상 입문자, 교육 콘텐츠 기획자, 1인 콘텐츠 제작자.
- 핵심 가치: FLOW, Midjourney, Kling, HeyGen, Suno에 복사해 사용할 수 있는 전문 프롬프트를 단계별로 만들고, 주인공과 등장인물의 외형·의상·소품 일관성을 유지한다.
- 서비스 범위: 이 앱은 이미지, 영상, 음악을 직접 생성하지 않고 각 도구에서 생성할 때 사용할 프롬프트를 작성한다.

## 2. 페이지/섹션 구성

- 홈: 서비스 소개, 지원 도구, 제작 시작 버튼.
- 프롬프트 작성: 스토리 내용, 주인공/등장인물 메모, 레퍼런스 이미지, 대상, 전문 동화책 시각 스타일, 장면 수, 영상 길이, 최대 2개 이미지/영상 프롬프트 도구, 수노 옵션, 52가지 음악 스타일, 음악 프롬프트 직접 입력.
- 캐릭터시트: 주인공과 등장인물의 캐릭터 시트 생성 프롬프트를 영어/한국어 병기로 아코디언 표시.
- 스토리보드: 장면별 요약, 이미지 생성 프롬프트, 영상 생성 프롬프트, 도구별 최적화 결과를 아코디언 표시.
- 음악: 수노용 배경음악 생성 프롬프트와 가사를 영어/한국어 병기로 아코디언 표시.

## 3. 핵심 AI 기능

- 입력: 스토리 내용, 주인공/등장인물 메모, 최대 5개의 레퍼런스 이미지, 대상 독자, 시각 스타일, 3~10장면 범위의 장면 수, 6초~1분 30초 범위의 영상 길이, 최대 2개 프롬프트 도구, 수노 가사 포함 여부.
- 처리: JavaScript가 입력값을 JSON으로 묶어 `fetch('/api/generate')`로 Python Serverless Function에 전달한다. Python 함수는 `generation_step` 값에 따라 시나리오, 캐릭터 시트, 이미지/영상 프롬프트, 수노 음악 프롬프트를 순차적으로 생성한다.
- 출력: 프로젝트 제목, 로그라인, 캐릭터 시트 생성 프롬프트, 장면별 영상 스토리보드, FLOW/Midjourney/Kling/HeyGen용 이미지 생성 프롬프트와 영상 생성 프롬프트, 수노 배경음악 생성 프롬프트와 가사.
- 사용자 가치: 동화책급 전문성과 영상 기획 흐름을 유지하면서 도구별 프롬프트 작성 시간을 줄인다.

## 4. 캐릭터 시트 기능

캐릭터 시트는 주인공과 등장인물이 장면마다 다르게 생성되는 문제를 줄이기 위한 일관성 기준표다.

출력 항목:

- 캐릭터 이름 영어/한국어
- 역할 영어/한국어
- 외형 영어/한국어
- 의상 영어/한국어
- 성격 영어/한국어
- 반복 유지 규칙 영어/한국어
- 캐릭터 시트 프롬프트 영어/한국어
- 네거티브 프롬프트 영어/한국어

활용 기준:

- 장면 이미지를 만들기 전에 캐릭터 시트를 먼저 생성한다.
- 머리색, 얼굴형, 의상, 대표 소품, 색상 팔레트, 나이대, 실루엣을 고정한다.
- 장면별 프롬프트에는 해당 캐릭터의 핵심 유지 규칙을 포함한다.
- 기존 유명 캐릭터나 작가·스튜디오 스타일을 그대로 복제하지 않는다.

## 5. 도구별 프롬프트 기준

| 도구 | 이미지 프롬프트 핵심 | 영상 프롬프트 핵심 |
| --- | --- | --- |
| FLOW | 인물·공간·조명·참조 요소·화면비 | 장면 연속성, 카메라 움직임, 시간 흐름 |
| Midjourney | 피사체, 구도, 매체, 색감, 조명, 비율 | 시작 프레임 기준 움직임, 짧고 명확한 동작 |
| Kling | 인물·소품·배경의 일관성 | Subject, Movement, Scene, Camera, Lighting |
| HeyGen | 아바타·배경·발표용 시각 자산 | 스크립트, 말투, 아바타 행동, 내레이션 |
| Suno | 장르, 분위기, BPM, 악기, 보컬 | 가사 구조, 장면 감정선, 피해야 할 요소 |

## 6. UI/UX 설계

- 전체 구조: 반응형, 블록형 카드, 아코디언 결과.
- 입력 UX: 장면 수와 영상 길이는 선택값을 쓰거나 직접 입력 버튼으로 세부 값을 넣을 수 있다.
- 단계 UX: 사용자는 2번 시나리오, 3번 캐릭터 시트, 4번 이미지·영상 프롬프트, 5번 수노 음악 프롬프트 버튼을 차례대로 눌러 결과를 만든다.
- 도구 UX: 이미지/영상 프롬프트 도구는 기본 체크 없이 시작하며, 한 번에 최대 2개까지만 선택할 수 있다.
- 레퍼런스 UX: JPG, PNG, WebP, GIF, AVIF, HEIC, TIFF, BMP, SVG 등 다양한 이미지 형식을 최대 5개까지 한 번에 선택하고 파일명·형식·용량을 확인한다.
- 음악 UX: 클래식, K-pop, 국악, 다큐멘터리, 재즈, 전자음악 등 52가지 음악 스타일을 아코디언 안의 버튼형 옵션으로 선택한다.
- 예시 UX: 예시 채우기 버튼은 전체 랜덤으로 작동하고, 분야별 예시 버튼은 동화·다큐·전통·환경·과학·문화·역사·생활·교육·종교·기독교·불교·광고·여행·인터뷰 분야마다 5개 예시 중 하나를 랜덤으로 입력한다.
- 버튼 UX: 주요 실행 버튼 묶음은 접고 펼칠 수 있는 아코디언 안에 배치한다.
- 결과 UX: 캐릭터, 장면, 음악 결과를 각각 아코디언으로 표시한다.
- 모바일: 한 열 레이아웃, 버튼 100% 너비, 가로 스크롤 방지.
- 접근성: 명확한 버튼 라벨, 키보드 포커스, 충분한 색상 대비, 본문 16px 이상.
- 보너스 UX: 다크 모드 제공.

## 7. 실패 처리 기준

- 빈 입력: 프론트엔드에서 즉시 필수 입력 안내 표시.
- 도구 미선택: 이미지/영상 프롬프트 생성 단계에서 최소 1개 이상의 도구 선택 안내 표시.
- 레퍼런스 이미지 초과: 5개 초과 선택 시 다시 선택 안내 표시.
- 장면 수 오류: 3~10개 사이 입력 안내 표시.
- API 키 누락: 백엔드에서 환경 변수 누락 안내 반환.
- API 오류: 사용자에게 다시 시도 안내 표시.
- 지연/타임아웃: 45초 이상 응답이 없으면 장면 수를 줄이거나 다시 시도하도록 안내.

### 7.1 응답 지연 개선 설계

- 기본 모델은 `OPENAI_MODEL` 환경변수로 관리해 빠른 모델과 고품질 모델을 쉽게 바꿀 수 있게 한다.
- 기본 장면 수는 낮게 시작하고, 최대 10장면까지만 허용해 한 번의 AI 응답이 과도하게 길어지지 않게 한다.
- 45초 타임아웃이 발생하면 장면 수 축소, 입력 요약, 재시도 안내를 제공한다.
- 후속 버전에서는 같은 입력과 옵션으로 요청한 결과를 `localStorage` 또는 서버 저장소에 캐시해 반복 호출을 줄인다.
- 긴 입력은 핵심 인물, 배경, 사건, 분위기 중심으로 요약한 뒤 AI에 전달하는 요약 프리프로세싱을 추가할 수 있다.
- 현재 버전은 먼저 장면 제목과 스토리보드만 생성하고, 캐릭터 시트와 이미지/영상 프롬프트, 음악 프롬프트를 순차 생성하는 단계형 생성 방식을 적용한다.

## 12. 배포 문제 진단 및 재배포 절차

배포 문제가 생기면 다음 순서로 확인한다.

1. Vercel 프로젝트의 **Deployments** 메뉴에서 최신 배포 상태를 확인한다.
2. 실패한 배포가 있으면 **Build Logs**를 열어 오류 메시지를 확인한다.
3. 배포는 Ready인데 화면이 오류이면 브라우저 개발자 도구의 Console과 Network에서 `/api/generate` 요청 상태를 확인한다.
4. 환경변수 `OPENAI_API_KEY`, `OPENAI_MODEL`이 Vercel에 등록되어 있는지 확인한다.
5. `api/index.py`, `vercel.json`, `requirements.txt` 수정 후 GitHub에 다시 push한다.
6. Vercel 자동 재배포가 완료되면 실제 URL에서 홈, 메뉴 이동, 입력, 결과 표시, 모바일 화면을 다시 확인한다.

실제 프로젝트에서 해결한 대표 오류:

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| Python entrypoint 오류 | Vercel이 함수 진입점을 찾지 못함 | `api/index.py`를 기준 엔드포인트로 정리 |
| 501 GET 오류 | 루트 GET 요청을 처리하지 못함 | `do_GET`으로 `index.html`, `css`, `js`, `images` 파일 응답 |
| API 연결 실패 | 환경변수 또는 API 라우팅 문제 | Vercel 환경변수와 `/api/generate` rewrite 확인 |

## 13. 운영 자동화 및 저장 고도화 계획

선택 보너스 확장으로 다음 기능을 추가할 수 있다.

- 사용자가 생성한 결과 JSON을 프로젝트별로 저장한다.
- 문의/폼 입력을 Google Sheets, Airtable, Notion 같은 외부 도구에 저장한다.
- 결과 생성 완료 후 사용자에게 다운로드 또는 이메일 전달 옵션을 제공한다.
- 방문자 분석을 연결해 어느 섹션에서 사용자가 많이 이탈하는지 확인한다.
- 자주 쓰는 프롬프트 템플릿을 저장해 다음 프로젝트에서 재사용한다.

현재 MVP에서는 다크 모드, 2D 입체 버튼, 아코디언, 복사 버튼, 직접 수정 버튼, 레퍼런스 이미지 삭제 버튼을 통해 UX 고도화 보너스 조건을 우선 충족한다.
